Update step-1, in case the students already have an ubuntu machine with WSL but forgot it's password. like this: # Reset Ubuntu (WSL) User Password

1. Open **PowerShell** or **Command Prompt**.
2. Start Ubuntu as the root user:
   ```powershell
   wsl -u root
   ```
3. Reset your user password:
   ```bash
   passwd <username>
   ```
   Example:
   ```bash
   passwd lokesh
   ```
4. Enter the new password twice.
5. Exit root:
   ```bash
   exit
   ```
6. Launch Ubuntu normally and log in using the new password.

> **Tip:** If you forgot your username, run:
>
> ```bash
> ls /home
> ```
